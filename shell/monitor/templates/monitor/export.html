Export the data

You get a zip with four CSV files: participants.csv, answers.csv, scores.csv (the scales of the results, from the latest answers) and transcripts.csv. Answers and transcripts are decrypted in the file. Times are in {{ study.time_zone }}.

{% csrf_token %}

Participants are numbered 1, 2, 3 … in order of sign-up, the same number in every file. The files can be joined to each other, but a row cannot be traced to a person. Use this for analysis.

Each row carries the participant's 4-character code. Whoever has the file and sees a code can link that person to their answers and chat. Use this only when a study needs it, for example to honour a removal request, and treat the file as personal data.
